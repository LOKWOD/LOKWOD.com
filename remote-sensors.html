Distributed sensing

The main controller is rarely located where the best measurement belongs.

LOKWOD Remote Sensors are small wireless nodes built to place temperature and environmental measurements where they are useful.

Flexible placement

Move the measurement, not the controller

A remote node can serve rooms, ducts, equipment spaces, mechanical areas, or other locations that should influence a central system.

Local commissioning

Setup and diagnose at the device

A local web interface supports initial configuration and status checks without requiring a specialized mobile application.

Wireless integration

Send the measurement to the system that needs it

The node is designed as a reusable input platform for the HVAC controller and future LOKWOD monitoring projects.

OTA-ready

Update after the node is installed

Remote firmware capability reduces the need to retrieve a mounted device for every software revision.

Node architecture

Small enough to distribute. Capable enough to maintain.

01

ESP32-C3 platform

A compact Wi-Fi-capable microcontroller provides the node's processing and connectivity base.

02

Local web interface

Device status and setup remain available directly on the local network.

03

Automatic update path

Firmware can be designed to check for approved releases without opening the enclosure.

04

Sensor flexibility

The platform can adapt to temperature, humidity, pressure, contact, or other supported inputs.

05

Signal visibility

Connection state and signal quality make installation troubleshooting more direct.

06

System identity

Named nodes let dashboards describe the actual room or equipment location.

HVAC use

Room-level temperature without a wall full of thermostats.

Remote nodes can feed the central controller the temperatures that matter while the head unit manages equipment and zones.

  • Office, bedroom, workshop, or equipment-room placement
  • Support for room-priority or averaging strategies
  • Installation visibility through local diagnostics

Future use

A reusable edge-sensing platform.

The same local setup and update pattern can support other property measurements as LOKWOD systems expand.

  • Mechanical-room temperature
  • Freeze-risk monitoring
  • Equipment contacts and state inputs
  • Environmental and utility measurements
Development note: Remote Sensor hardware and supported sensor combinations are still evolving. Final radio range, power method, enclosure, and environmental ratings depend on the completed configuration.
