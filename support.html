HVAC Controller

Basic controller checks.

Do not change line-voltage wiring, refrigerant equipment, or HVAC safety controls unless qualified to do so.

The display is dark

Tap once and release. A sleeping display should wake to the clock without activating a control. If it remains dark, verify the controller has power and that the backlight or display connection has not been disturbed.

The local dashboard does not open

Confirm the phone or computer is connected to the same property network. Check the controller's network status and current IP address, then browse directly to that address.

A remote sensor is missing

Verify the sensor node has power, joined the expected Wi-Fi network, and reports a healthy signal. Confirm its configured identity matches the room shown by the controller.

An update does not complete

Confirm the update manifest and firmware are reachable, the version is newer, and the controller has stable power. Use the documented local recovery path rather than repeatedly interrupting an in-progress flash.

Well Monitor

Basic monitor checks.

Never open energized well-pump wiring or alter a pressure system unless you understand the electrical and mechanical hazards.

The displayed pressure looks wrong

Compare the reading with a known mechanical gauge, verify the configured sensor range, and confirm the sensor is connected to the expected input. A wrong range can make a healthy signal appear incorrect.

The monitor says the pump is running when it is not

Review the configured current threshold and sensor orientation. Electrical noise, an incorrect current-transformer installation, or a threshold set too low can create false running state.

Intelligence is not making conclusions yet

The analysis engine needs sufficient normal behavior to establish confidence. Review learning progress and make sure vacation or irrigation modes are not masking the period you expect it to evaluate.

The update page is needed

Use the device's local update or recovery page from the same network. Keep power stable and use firmware built for the exact hardware and partition configuration.

Remote Sensors

Basic node checks.

Begin with power and network status before replacing the attached sensor.

The node does not appear on Wi-Fi

Confirm the board is powered by a known-good cable and supply. If the node has never been configured, check for its setup access point; if it was configured before, confirm the saved network is still available.

The reported value does not change

Check the sensor connection, configured input type, and last-update time. A healthy network link does not prove the physical sensor is reporting.

Signal quality is poor

Move the node temporarily closer to the access point, then separate radio-placement problems from sensor-cable or power problems. Dense construction and mechanical equipment can reduce range.

Emergency and safety conditions: If equipment is overheating, leaking, arcing, flooding, producing smoke or odor, or operating outside safe pressure or temperature limits, shut it down only if safe to do so and contact the appropriate qualified professional.
