# LOKWOD.com

Official public website for LOKWOD.

## Publishing

This repository is designed for GitHub Pages from the `main` branch and repository root.

- Custom domain: `lokwod.com`
- Analytics: Cloudflare Web Analytics
- Static site: HTML, CSS, and JavaScript
- No build step required

## Local preview

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.
