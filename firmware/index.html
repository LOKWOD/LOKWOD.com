How it works

Safe updates without the guesswork.

01

Check

Your controller contacts the official LOKWOD release server over HTTPS.

02

Verify

Version, hardware, file size, image format, and SHA-256 signature are checked.

03

Install

The new image is written to a separate update partition while the current version remains safe.

04

Protect

If the new firmware cannot start correctly, the controller automatically rolls back.

First-time setup

The HVAC controller needs one final USB flash.

The secure updater changes the controller's flash partition layout. Install that foundation once by USB; every compatible release after it can be installed directly from the controller over Wi-Fi.
