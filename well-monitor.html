Private well visibility

The pump should not have to fail before the system gets your attention.

LOKWOD Well Monitor combines pressure, pump current, cycling behavior, recovery, and configurable equipment information into one local view.

Pressure behavior

Watch cut-in, cut-out, recovery, and stability

One- or two-sensor modes support system pressure monitoring and filter-side comparisons without reducing the installation to a single snapshot.

Pump current

Know when the pump is running—and when it runs too long

Current sensing provides an independent operating signal that can be compared with pressure response and runtime.

Installation profile

Store the actual equipment configuration

Tank capacity, precharge, pressure-switch settings, pump type, horsepower, voltage, wiring, rated flow, well depth, sensor range, and current threshold remain with the device.

Behavior analysis

Learn patterns before labeling them failures

LOKWOD Intelligence evaluates runtime by hour and weekday, pressure recovery, pump current, operating modes, and recent events to produce homeowner-friendly guidance.

LOKWOD Intelligence

Confidence-based behavior analysis.

Fixed rules can mistake irrigation, guests, or normal morning use for a leak. The analysis engine adds time, operating mode, pressure recovery, and current behavior before escalating a finding.

  • Learns patterns by hour and weekday
  • Accounts for vacation and irrigation modes
  • Tracks learning progress and recent events
  • Explains findings in plain language

Update + recovery

Maintainable after installation.

The firmware supports local update access and HTTPS cloud delivery with version checks, download-size validation, and SHA-256 verification before selecting a new boot partition.

  • Local recovery page
  • Dual application partitions
  • Versioned manifest delivery
  • Size and digest verification

What it can help surface

Observations worth investigating.

The monitor is intended to help an owner recognize abnormal behavior—not replace a qualified well professional, electrician, or plumber.

01

Extended runtime

Pump current remains active longer than the learned or configured expectation.

02

Poor recovery

Pressure does not respond as expected while the pump is operating.

03

Short cycling

Repeated starts and stops suggest a tank, switch, leak, or configuration concern.

04

Growing restriction

A two-sensor installation can reveal increasing differential pressure across filtration.

Safety note: This project is a monitoring aid. It does not make a private well, pressure system, electrical installation, or water supply safe by itself. Installation and repairs should follow applicable codes and qualified professional guidance.
