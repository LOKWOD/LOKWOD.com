The control surface

A thermostat should make the system easier to understand.

LOKWOD HVAC Controller combines equipment control, zone visibility, weather context, and local access in one purpose-built interface.

Touchscreen interface

Clock, thermostat, dampers, and system information

The primary screens are organized as a horizontal swipe sequence. The display returns to the clock after inactivity and sleeps later without stopping HVAC logic or networking.

Zoned airflow

Direct visibility into motorized dampers

Dedicated damper controls expose zone state instead of hiding airflow decisions behind a generic temperature reading.

Local control

Browser dashboard on the property network

Settings and system status can be accessed without walking to the head unit, while the controller continues to operate locally.

Serviceability

Firmware updates with a deliberate recovery path

Over-the-air delivery is paired with versioning, validation, and local access so the device remains maintainable as features evolve.

Designed as a system

Climate control is more than one temperature number.

The controller brings together the measurements, outputs, and operating context needed for a more capable residential HVAC interface.

Heat + cool outputs

02

03

Remote measurements

Wireless sensor nodes extend temperature data beyond the controller location.

04

Weather context

Time, date, weather, air quality, UV, moon phase, and barometric information support an informative idle display.

05

Wake protection

The first sleeping-screen touch wakes the display and is consumed before controls accept input.

06

Remote dashboard

Local browser access exposes setpoints, zones, status, and update information.

Interaction model

Useful when awake. Invisible when not needed.

The interface is designed to behave like a premium wall control rather than a constantly glowing tablet.

  • Boots to a persistent clock screen
  • Horizontal swipe between primary screens
  • Returns to clock after short inactivity
  • Display-only sleep after extended inactivity
  • Wake touch never changes a setting

Operating principle

Control stays local.

Networking adds convenience and updates; it is not supposed to replace the controller's responsibility to run connected equipment.

  • HVAC logic continues when the display sleeps
  • Local network access remains available
  • Background tasks continue independently
  • System state is visible instead of implied
